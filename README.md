# GNS Shipping Agency — Website

Corporate website I built for **GNS Gemi Acenteliği ve Lojistik Ltd. Şti.**, a ship agency and logistics company based in İskenderun, Türkiye.

The site is fully static. I deliberately kept it free of frameworks, bundlers and runtime dependencies: it is plain HTML, one stylesheet and native ES modules, so it loads fast, deploys anywhere and has nothing to keep updated. The only build step is a small standard-library Python script that renders the English page.

## Features

- Bilingual: Turkish at `/`, English at `/en/`, each served as fully translated markup with `hreflang` alternates
- Scroll-spy navigation and scroll-triggered reveal animations via `IntersectionObserver`
- Responsive layout from wide desktop down to small phones, with an accessible mobile menu (`aria-expanded`, Escape to close, focus return)
- Client-side validated contact form
- `LocalBusiness` structured data (JSON-LD) and Open Graph tags for search and link previews

## Project structure

```
index.html              Markup, authored in Turkish, plus an inline SVG icon sprite
en/index.html           English page, generated by scripts/build_en.py (not committed)
scripts/build_en.py     Renders the English page from index.html and js/locales/en.js
robots.txt, sitemap.xml Crawler directives and sitemap for search engines
css/style.css           Design tokens, components and responsive rules
js/main.js              Entry point, wires up the modules
js/modules/
  i18n.js               Runtime strings for the page language, legacy ?lang= redirect
  header.js             Sticky header and mobile navigation
  reveal.js             Scroll reveal animations
  scroll-spy.js         Active nav link tracking
  contact-form.js       Validation and mail hand-off
js/locales/             Translation dictionaries
img/                    Logo, icons, section photos, ports map (TR and EN)
```

## Running locally

ES modules do not load over `file://`, so the site has to be served over HTTP:

```sh
make serve        # builds /en/, then serves http://localhost:5173
```

Any static server works after `make build`; the Makefile just wraps `python3 -m http.server`.

## How the i18n works

Each language is its own page, so search engines index both and links can point at either. I didn't want to maintain two copies of the markup, so the Turkish `index.html` is the single source:

- `data-i18n="key"` marks an element whose text is translatable
- `data-i18n-attr="content:key; aria-label:key"` marks translatable attributes

`make build` runs `scripts/build_en.py`, which substitutes the strings from `js/locales/en.js` and writes `en/index.html`. It also sets `<html lang>`, the canonical URL and Open Graph locale, and marks EN as the current language in the switcher. The build is strict: an unknown key, a binding that wraps anything other than plain text, or a missing attribute fails the build instead of shipping a half-translated page.

Attributes can carry asset paths as well. The ports map has its text baked into the image, so its `src` and `srcset` are bound to locale keys. Asset paths are root-relative so the same markup works under `/en/`.

At runtime, `i18n.js` reads the page language from `<html lang>` and only serves strings that exist in JavaScript alone (form feedback, menu labels); `js/locales/tr.js` holds the Turkish ones. Old `?lang=en` links redirect to `/en/`.

To add a translated string:

1. Add `data-i18n="section.key"` to the element in `index.html`.
2. Add `'section.key'` to `js/locales/en.js`.
3. Run `make build`.

## Contact form

There is no backend, so on submit the form validates the fields and opens the visitor's mail client with a prefilled message addressed to `data-recipient` on the `<form>`. If the client later wants submissions stored server-side, the only change needed is replacing `buildMailto()` in `contact-form.js` with a `fetch()` to a form endpoint.

## Deployment

The site is hosted on Cloudflare as static assets.

```sh
make package      # builds /en/ and creates dist/gns-site.zip
```

I upload the zip from **Workers & Pages → project → Create deployment**. The output is plain static files, so the same zip works on Netlify, GitHub Pages or any static host.

## Browser support

All current evergreen browsers. The code uses ES2022 features (`Object.hasOwn`, optional catch binding) and degrades gracefully where `IntersectionObserver` is unavailable.
